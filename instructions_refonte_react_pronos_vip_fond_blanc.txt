## 1. NETTOYAGE & RESET DE L'ANCIEN CODE SOURCE

Pour repartir sur des bases saines et supprimer l'ancien design sombre ou obsolète :

1. Dans votre fichier global CSS (`src/index.css` ou `src/App.css`) :
   - Supprimez toutes les classes d'arrière-plan sombre résiduelles (`bg-gray-900`, `bg-slate-950`, `#0f131d`, etc.).
   - Supprimez les styles CSS personnalisés non structurés.
   - Appliquez le reset de base sur le body :
   ```css
   @tailwind base;
   @tailwind components;
   @tailwind utilities;

   body {
     background-color: #ffffff;
     color: #0f172a;
     font-family: 'Inter', -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif;
     -webkit-font-smoothing: antialiased;
   }
   ```

2. Configuration `tailwind.config.js` :
   Remplacez la section `theme.extend` pour intégrer directement la nouvelle palette :
   ```javascript
   module.exports = {
     content: ["./src/**/*.{js,jsx,ts,tsx}"],
     theme: {
       extend: {
         colors: {
           brand: {
             DEFAULT: '#4D8EFF',
             light: '#EBF2FF',
             dark: '#2B6EE3',
             hover: '#3A7BEB'
           },
           surface: {
             base: '#FFFFFF',
             subtle: '#F8FAFC',
             muted: '#F1F5F9',
             border: '#E2E8F0'
           },
           success: {
             DEFAULT: '#10B981',
             light: '#ECFDF5',
             text: '#047857'
           },
           danger: {
             DEFAULT: '#EF4444',
             light: '#FEF2F2',
             text: '#B91C1C'
           }
         }
       }
     },
     plugins: []
   }
   ```

## 2. PRINCIPES DU DESIGN SYSTEM (FOND BLANC & ACCENT BLEU)

- **Fond d'application** : Blanc pur `#FFFFFF`.
- **Conteneurs / Cartes** : Blanc pur `#FFFFFF` avec fine bordure `border border-slate-200` et ombre douce `shadow-sm`, ou fond subtil `#F8FAFC`.
- **Couleur Primaire / Accent** : `#4D8EFF` pour tous les boutons principaux (CTA), badges actifs, jauges et liens clés.
- **Typographie** :
  - Titres : `#0F172A` (Slate 900), gras (`font-bold`).
  - Textes secondaires : `#64748B` (Slate 500).
- **Statuts & Cotes** :
  - Badge Gagné : Fond vert doux `#ECFDF5`, texte `#047857`.
  - Cotes : Chiffre bleu `#4D8EFF` ou `#0F172A` dans un encadré net `bg-slate-100` ou `bg-blue-50`.

```jsx
// src/components/layout/BottomNav.jsx
export function BottomNav({ activeTab, setActiveTab }) {
  const tabs = [
    { id: 'pronos', label: 'Pronos', icon: '⚽' },
    { id: 'combines', label: 'Combinés', icon: '📋' },
    { id: 'stats', label: 'Stats', icon: '📈' },
    { id: 'vip', label: 'VIP Club', icon: '⭐' },
  ];

  return (
    <nav className="fixed bottom-0 left-0 right-0 z-50 bg-white border-t border-slate-200 px-3 py-2 flex justify-around">
      {tabs.map((tab) => {
        const isActive = activeTab === tab.id;
        return (
          <button
            key={tab.id}
            onClick={() => setActiveTab(tab.id)}
            className={`flex flex-col items-center gap-1 text-xs font-semibold py-1 px-3 rounded-lg transition-colors ${
              isActive ? 'text-[#4D8EFF]' : 'text-slate-400 hover:text-slate-600'
            }`}
          >
            <span className="text-base">{tab.icon}</span>
            <span>{tab.label}</span>
          </button>
        );
      })}
    </nav>
  );
}
```

## 5. CHECKLIST DE DÉPLOIEMENT

1. **Supprimer le CSS sombre hérité** : inspecter le `body` et les classes Tailwind dans `App.jsx`.
2. **Vérifier les contrastes WCAG** : Le texte sombre `#0F172A` sur fond `#FFFFFF` offre un ratio supérieur à 12:1 (parfait pour la lecture mobile).
3. **Optimiser les assets** : Utiliser des icônes SVG légères (Lucide-React ou Heroicons) teintées en `#4D8EFF` ou `#64748B`.
4. **Tester sur mobile** : Tous les boutons disposent d'une zone tactile minimale de 44px de hauteur pour un confort optimal au clic.
